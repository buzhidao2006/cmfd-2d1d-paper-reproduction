# 第六阶段：最小二维特征线定源求解器

本阶段第一次引入独立的二维特征线（MOC）积分。空间限定为**周期方形直角网格**；每个方向仅用一条穿过每个单元的对角线轨迹，方向为 `(±1, ±1)`。在各单元的平源近似下，沿长度 `L = √2 h` 的轨迹精确积分：

```text
ψ_out = exp(-Σt L) ψ_in + [1 - exp(-Σt L)] Q_track / Σt
ψ_average = Q_track / Σt
            + (ψ_in - Q_track / Σt) [1 - exp(-Σt L)] / (Σt L)
```

周期边界把每条轨迹的出射通量接到下一单元的入射通量。散射源由上一内迭代的轨迹加权平均标量通量计算；可提供固定的方向相关轴向横向泄漏作为输入。这个求解器尚未与已有的轴向 SN 代码交换泄漏。

验证包含：在不同方向、非方形单元**排列**（但每个单元仍为正方形）上制造周期面通量并恢复；逐轨迹检查出入流、碰撞和源项的积分平衡；均匀介质下检查常数源与散射迭代极限；检查给定轴向泄漏的方向平衡。

运行：`python -m pytest tests/test_moc_2d.py -v`。

**适用边界：** 一条对角轨迹/单元不能代表单元面积上的完整空间积分，也没有论文采用的多方位角、多极角和射线间距、复杂几何、真实截面、3D 2D/1D 耦合、CMFD 加速或裂变本征值。因此本模块是方法验证原型，不应拿它的数值与论文图表直接比较。
