# 第五阶段：三维粗网格电流一致性

本阶段把[一维电流修正](STAGE4_CMFD_1D.md)扩展到周期三维直角网格。每个粗网格有给定的标量通量，每个正向界面有给定的输运电流；程序分别构造 x、y、z 界面的扩散系数与修正系数，再组装定源 CMFD 平衡。

每个方向都使用论文第 (7) 式的界面关系。对轴向 `z`，例如：

```text
Jz[i,j,k+1/2] = -D̃z[i,j,k+1/2] (Φ[i,j,k+1] - Φ[i,j,k])
                 -D̂z[i,j,k+1/2] (Φ[i,j,k+1] + Φ[i,j,k])
```

三个方向的电流散度与吸收项构成定源方程：

```text
(Jx_right - Jx_left)/hx + (Jy_right - Jy_left)/hy
  + (Jz_right - Jz_left)/hz + Σa Φ = Q
```

验证分为三层：制造三维通量和电流并检查电流修正能精确恢复它们；把已有轴向 SN 的面电流延展到径向均匀的三维网格，检查三维方程退化回轴向方程；核对显式矩阵与直接电流散度算子一致。测试同时检查全域周期电流的净散度为零。

运行：`python -m pytest tests/test_cmfd_3d.py -v`。

当前矩阵用稠密形式构造，仅供最多 216 个粗网格的验证用途。尚无 2D MOC 输运、横向泄漏的自洽交换、裂变本征值或论文算例数据。电流一致性和定源方程自洽**不等于**论文 CMFD 加速方法已复现，也没有验证其稳定性结论。
