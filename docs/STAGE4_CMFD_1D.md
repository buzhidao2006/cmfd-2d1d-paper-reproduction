# 第四阶段：一维 CMFD 界面电流一致性

本阶段以论文第 (7) 式为依据，单独实现**周期一维、单群、定源**粗网格电流关系。它与论文真正的三维 CMFD 本征值迭代不同；这里也没有二维 MOC 或两方向横向泄漏的自洽耦合。

令第 `i` 个粗网格宽度为 `h_i`，右界面为 `i+1/2`。按照论文的符号约定：

```text
D_i        = 1 / (3 Σt_i) + θ h_i
D̃_i+1/2   = 2 D_i D_(i+1) / (D_i h_(i+1) + D_(i+1) h_i)
J_i+1/2   = -D̃_i+1/2 (Φ_(i+1) - Φ_i)
            -D̂_i+1/2 (Φ_(i+1) + Φ_i)
D̂_i+1/2   = -[J_transport + D̃_i+1/2 (Φ_transport,i+1 - Φ_transport,i)]
             / (Φ_transport,i+1 + Φ_transport,i)
```

`θ=0` 对应标准扩散系数，`θ=0.25` 是论文 pCMFD 使用的参数。这里的 `θ` 只影响界面系数；实现该参数**不等于**已经复现 pCMFD 的加速性能。

冻结 `D̃` 和 `D̂` 后，组装并求解一维定源平衡：

```text
(J_i+1/2 - J_i-1/2) / h_i + Σa_i Φ_i = Q_i
```

验证包括：先指定通量和界面电流，再反求修正系数与源项，检查原通量能由粗网格方程恢复；另外用[第二阶段](STAGE2_AXIAL_SN.md)无散射轴向 SN 的面角通量形成输运电流，检查修正后的 CMFD 方程重建该 SN 解。周期总电流散度在全域求和后相抵。

运行：`python -m pytest tests/test_cmfd_1d.py -v`。

这只是**电流一致性测试**，不能据此声称已经得到论文的谱半径、迭代次数或 VERA/KUCA/KAIST 算例。下一步仍需二维 MOC、三维粗网格耦合、裂变本征值及论文算例数据。
