# 第二阶段：轴向 1D SN 离散验证

本阶段实现论文第 2.1 节轴向方程的一个可独立检查的离散子问题：在单群、均匀总截面、周期边界下，对每个离散方向求解轴向输运，并用菱形差分定义网格中心角通量。参考论文第 (2a)、(4b)、(5b) 式；这里的径向横向泄漏被当作给定输入，**没有**由二维 MOC 求解器计算。

对网格 `j`、方向余弦 `μ`、网格宽度 `h`，实现的方程是

```text
μ (ψ[j+1/2] - ψ[j-1/2]) / h + Σt ψ[j]
    = Q[j] + Σs φ_previous[j] - TL_radial[j, μ]
ψ[j] = (ψ[j-1/2] + ψ[j+1/2]) / 2
φ[j] = Σ_direction weight[μ] ψ[j, μ]
```

一次内迭代把上一步标量通量作为散射源，对各方向求解周期边界线性系统，再取加权角平均。可设定内迭代次数，但这不是论文完整的 2D/1D 外迭代或 CMFD 加速。

## 独立验证

- 构造复指数周期面通量，代回离散方程得到源，再检查求解器恢复同一面通量及中心通量。
- 常数源下，随着散射源迭代收敛，解趋于 `Q / (Σt - Σs)`。
- 周期边界使全域流出入相抵；检查全域吸收、源和给定横向泄漏的离散平衡。
- 一网格周期情形退化为局部平衡；错误形状与非法截面输入必须报错。

运行：`python -m pytest tests/test_axial_sn.py -v`。

## 尚缺的论文级内容

二维 MOC 特征线追踪、两方向泄漏的自洽交换、3D CMFD 界面电流修正、裂变本征值迭代、论文基准的完整数据和几何均未实现。本阶段的数值不能与论文图表直接比较。菱形差分在高光学厚度下也可能出现非物理的面通量振荡；该代码首先验证离散方程，不用于工程分析。
